Sobre arco

Proyecto de portfolio

arco es una tienda de demostración creada por Alberto Arcones para mostrar el diseño y desarrollo de una aplicación de comercio electrónico basada en microservicios.

Qué demuestra este proyecto

  • Arquitectura de microservicios: servicios independientes de catálogo, pedidos y usuarios.
  • Una base de datos por servicio (PostgreSQL) y caché con Redis.
  • Un API Gateway con Nginx que unifica el acceso.
  • Contenerización completa con Docker y orquestación con Docker Compose.
  • Integración y despliegue continuos (CI/CD) con GitHub Actions.
